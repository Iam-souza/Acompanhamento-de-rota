# Project Summary
The project is a web application developed with Python and Streamlit, integrated with Supabase. It serves as a route tracking and reporting system, enabling users to log in, upload reports (CSV or Excel), and store data in Supabase. The application automates data consolidation and offers advanced data visualization and editing options, including filtering for thorough analysis and export. Recent enhancements have improved the column mapping for uploaded files and the validation of mandatory fields, ensuring compatibility with user data formats.

# Project Module Description
- **Authentication Module**: Manages user login, password hashing, and session management.
- **Database Module**: Handles Supabase configuration and CRUD operations for reports and users.
- **Utilities Module**: Provides functions for processing uploaded files, validating data, and exporting reports.
- **Main Application**: The core Streamlit application that integrates all functionalities.

# File Description Inventory
- **app.py**: The main application file that runs the Streamlit app and integrates all components.
- **auth.py**: Contains the authentication logic for user login and session management.
- **database.py**: Manages all interactions with the Supabase database, including data retrieval and insertion.
- **package.json**: Configuration file for managing frontend dependencies.
- **requirements.txt**: Lists all Python packages required for the project.
- **template_config.json**: Configuration for any templates used in the application.
- **todo.md**: A markdown file outlining tasks and features to be implemented in the project.
- **utils.py**: Contains utility functions for data processing and validation.

# Technology Stack
- **Language**: Python 3
- **Framework**: Streamlit
- **Database**: Supabase (PostgreSQL)
- **Libraries**: 
  - `streamlit` for building the web application
  - `supabase` for database interaction
  - `pandas` for data manipulation
  - `openpyxl` for Excel file handling
  - `bcrypt` for password hashing
  - `python-dotenv` for environment variable management
